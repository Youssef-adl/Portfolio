# AGENTS.md — Youssef Adlani Portfolio

## Tech Stack
- React + Vite
- Tailwind CSS
- GSAP + Lenis (scroll)
- Three.js (available but not used in Hero)

## Design Direction
- SaaS moderne gradient style (Vercel/Linear aesthetic)
- Colors: Maroon `#800020` & Camel `#c5a059` (Luxury Editorial)
- Fonts: Cormorant Garamond (headings) & Plus Jakarta Sans (body)
- Glassmorphism, gradient text, noise overlay, grid dots
- Minimal animations — only essential reveals
- No decorative bloat (no Stats, Marquee, StickyText)

## Code Principles
- Ship fast, ship clean
- Concise output, no unnecessary explanations
- Quality over quantity
- No over-engineering
- No comments unless asked
- Prefer editing existing files

## Sections (in order)
1. Hero — gradient bg + grid dots, no 3D
2. About — 2-column glass cards + portrait
3. Skills — bento grid glassmorphism
4. Projects — horizontal scroll
5. Experience — glass timeline
6. Education — 2-column glass
7. Contact — links + CV download
8. Footer — brand + nav + social

## Commands
- `npm run dev` — dev server
- `npm run build` — production build
